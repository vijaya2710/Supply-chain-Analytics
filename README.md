Supply Chain Analytics Dashboard

Project Overview

This project focuses on analyzing Supply Chain and Logistics data using Microsoft Power BI to understand business performance and identify key insights.

Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

Project Objectives

- Analyze supply chain performance.
- Monitor key business metrics.
- Understand logistics and operational trends.
- Identify areas for improvement through interactive visualizations.

Dashboard Features

- Interactive Power BI dashboard
- KPI cards
- Data visualizations
- Business performance analysis
